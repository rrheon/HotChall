# HotChall
ADS : 사용자들에게 요즘 뜨는 챌린지를 보여주고 챌린지를 저장하여 배워볼 수 있는 앱
# 주요기능
- 요즘 뜨는 챌린지를 보여줌
- 챌린지 저장기능
- 챌린지 배워보기
